# oiiiiii

Projeto standalone com a pagina do cracha 3D pronta para subir no GitHub.

## Estrutura

- `src/components/Lanyard.tsx`: componente principal do cracha 3D
- `src/assets/lanyard/`: GLB, textura do cordao e imagens usadas no cracha
- `src/App.tsx`: pagina unica da aplicacao

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Observacoes

- O projeto usa o `card.glb` original com fisica, cordao e arraste preservados.
- A arte da frente e do verso e projetada diretamente no mesh do cracha.
- A pasta `src/assets/lanyard/` tambem guarda imagens usadas durante as iteracoes para ficar tudo junto em uma unica raiz de projeto.

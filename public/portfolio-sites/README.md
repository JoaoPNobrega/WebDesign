# Portfolio Zoom Media

Put your 7 portfolio assets in this folder using the exact filenames below:

1. `site-01-opening.mp4`
2. `site-02-top-left.mp4`
3. `site-03-left-tall.mp4`
4. `site-04-center-right.mp4`
5. `site-05-bottom-left.mp4`
6. `site-06-bottom-wide.mp4`
7. `site-07-final-zoom.mp4`

Media roles:

- `site-01-opening.mp4`: center video
- `site-02-top-left.mp4` to `site-07-final-zoom.mp4`: muted looping videos

Which asset gets the strongest zoom:

- `site-07-final-zoom.mp4`

Recommended use for each slot:

- `site-01-opening.mp4`: center video, this is the middle slot of the composition
- `site-02-top-left.mp4`: secondary project or hero section capture in motion
- `site-03-left-tall.mp4`: tall layout, dashboard, mobile mockup, or stacked section
- `site-04-center-right.mp4`: another balanced full-page preview
- `site-05-bottom-left.mp4`: detail section, feature block, or UI close-up
- `site-06-bottom-wide.mp4`: wider composition with nice movement
- `site-07-final-zoom.mp4`: your best looping video, because this one receives the biggest finale zoom

Video recommendations:

- Use short clips, ideally 3 to 8 seconds
- Export without audio
- Make the loop feel seamless
- Prefer `mp4` with H.264 for compatibility

Notes:

- If you change extensions or filenames, also update the paths in `src/pages/PortfolioPage.tsx`.
- Until you add your own files, the page falls back to the current online static images.
